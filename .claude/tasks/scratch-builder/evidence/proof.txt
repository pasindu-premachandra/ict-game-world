WHAT WAS WRITTEN
----------------
  content/scratch.sinhala.json       34 strings  (3 structures, 14 programs)
  content/adventure-9.sinhala.json  348 strings  (18 games)
                                    --- 382 total

Both go through the same overlay pipeline grade 9 already used: keyed by the
English string, applied by scripts/lib/apply-sinhala.mjs, every touched node
marked siDraft: true, and a key matching nothing is a hard error so the file
cannot rot as the English changes underneath it.

Terms come from content/pages/word-bank.md, the NIE Sinhala-medium list, so
the bonus games and the builder cannot drift from the lessons:

  Sequence ............ අනුක්‍රමය
  Selection ........... තේරීම
  Repetition .......... පුනර්කරණය
  Control structure ... පාලන ව්‍යූහය
  Program ............. වැඩසටහන
  Variable ............ විචල්‍යය
  Array ............... ආරාව
  Sensor .............. සංවේදකය
  Mouse ............... මූසිකය

Eight UI strings in js/i18n.js were corrected to match: they had used
ක්‍රමලේඛ (programming, the subject) where the word bank says වැඩසටහන
(a program, the thing you build), and ව්‍යුහය where the NIE writes ව්‍යූහය.
